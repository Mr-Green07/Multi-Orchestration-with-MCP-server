## `src/` — Core Source Packages

### `src/audio/` — Audio I/O Pipeline

**Purpose:** Everything that touches raw PCM audio: microphone capture, wake word detection, VAD endpointing, and speaker playback.

| File | Contains | Push? |
|------|----------|-------|
| `capture.py` | `MicCapture` (PortAudio InputStream → 16 kHz int16 chunks), `Rebuffer` (fixed-frame splitter), `PrerollRing` (rolling audio history before wake). | ✅ |
| `wakeword.py` | `WakeWordEngine` — openWakeWord ONNX wrapper with debounce, cooldown, barge-in mode. Fires a detection event when "hey jarvis" is heard. | ✅ |
| `vad.py` | `VadEndpointer` — Silero VAD v5 ONNX wrapper. Turns a probability stream into `speech_start`, `endpoint`, and `timeout` events. `SileroOnnx` is the bare model runner. | ✅ |
| `output_handler.py` | `Playback` — sounddevice OutputStream with instant barge-in kill, silence fill, rate negotiation, and `enqueue()` / `end_of_utterance()` API for TTS. | ✅ |
| `__init__.py` | Package marker. | ✅ |

---

### `src/core/` — Pipeline Orchestration

**Purpose:** The finite state machine (FSM), event bus, config loader, and the new brain that wires STT → LLM → TTS together.

| File | Contains | Push? |
|------|----------|-------|
| `state.py` | `State` enum (IDLE / LISTENING / THINKING / SPEAKING) and `StateMachine` with valid transition guards. | ✅ |
| `events.py` | `Event` dataclass and `EventBus` — thread-safe publish/subscribe queue used between the audio thread and main loop. | ✅ |
| `brain.py` | `Brain` — the pipeline plug. Loads `Transcriber`, `LLMResponseGenerator`, and `TTSSynthesizer` at startup. `on_utterance()` chains STT → LLM → TTS → Playback on each captured utterance. | ✅ |
| `pipeline.py` | Alternative/older pipeline scaffolding. May overlap with `main.py`. Review for consolidation. | ⚠️ |
| `orchestrator.py` | High-level orchestrator scaffolding (early design, not yet used). | ⚠️ |
| `config.py` | Loads `.env` and `config.yaml`, exposes typed settings via `python-dotenv`. | ✅ |
| `constants.py` | Shared constants (sample rates, model names, etc.). | ✅ |
| `__init__.py` | Package marker. | ✅ |

### `src/asr/` — Speech-to-Text (Whisper)

**Purpose:** Converts captured audio (numpy array or file) into a text transcript using OpenAI Whisper.

| File | Contains | Push? |
|------|----------|-------|
| `transcriber.py` | `Transcriber` — full-featured Whisper wrapper. Accepts `np.ndarray` or file path, returns `TranscriptionResult` (text, confidence, language, segments). Used by `Brain`. | ✅ |
| `whisper_asr.py` | `WhisperASR` — simpler Whisper wrapper using `faster-whisper`. Reads from a separate `config/base.yaml`. Alternative to `transcriber.py`. | ✅ |
| `processor.py` | Audio pre-processing utilities for ASR (normalisation, resampling helpers). | ✅ |
| `exceptions.py` | `ASRError`, `ModelNotLoadedError`, etc. | ✅ |
| `__init__.py` | Package marker. | ✅ |

### `src/response_generation/` — LLM Response Engine

## `.env` — Environment Variables ❌ NEVER PUSH

Stores secrets and machine-specific settings. Create this from `.env.example`.

```env
MODEL_SIZE=small          # Whisper model: tiny | base | small | medium | large
DEVICE=cpu                # cpu | cuda
LANGUAGE=en
API_PORT=8000
MAX_UPLOAD_SIZE=500       # MB
DATABASE_URL=sqlite:///data/database/assistant.db
SECRET_KEY=<your-key>     # for encryption module
```

> Always add `.env` to `.gitignore`. Commit a `.env.example` with placeholder values instead.
